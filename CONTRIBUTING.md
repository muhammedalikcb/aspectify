# Contributing

Thanks for wanting to help with Aspectify.

1. Fork the repository and create a branch with a clear name, like `feature/add-something` or `fix/retry-count`.
2. Make your change. Keep it focused, one topic per pull request.
3. Add or update tests when you change behaviour. `./gradlew build` should pass.
4. Open a pull request and explain what changed and why.

A few things that help:

- Write commit messages that say what the change does.
- Follow the existing code style and package structure.
- If you change something users can see, update the README too.

# Katkı Rehberi

Aspectify'a katkı vermek istediğin için teşekkürler.

1. Repoyu fork'la ve açıklayıcı isimli bir branch aç, örneğin `feature/ozellik-ekleme` ya da `fix/retry-sayisi`.
2. Değişikliğini yap. Her PR tek bir konuya odaklansın.
3. Davranışı değiştiriyorsan test ekle ya da güncelle. `./gradlew build` geçmeli.
4. PR açıp neyi neden değiştirdiğini anlat.

İşe yarayan birkaç şey:

- Commit mesajında değişikliğin ne yaptığını yaz.
- Mevcut kod stiline ve paket yapısına uy.
- Kullanıcının göreceği bir şeyi değiştirdiysen README'yi de güncelle.
